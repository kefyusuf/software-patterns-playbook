# Enterprise Patterns

This directory covers enterprise-scale patterns that clarify real application boundaries: data access and mapping, boundary contracts, resilience, and cross-service consistency.

Covered today: DTO, Repository, Specification, Domain Event, Service Layer, Unit of Work, Data Mapper, Value Object, Lazy Load, Retry with Backoff, Circuit Breaker, Outbox, Inbox, and Saga.

Add new standalone guides only when they stay problem-first and do not turn enterprise patterns into default architecture. Future additions should explain the boundary pressure, simpler alternative, and failure modes that justify the pattern.
